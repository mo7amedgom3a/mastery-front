أضِفه إلى موقعك

الطريقة الأسرع سطر واحد في وسم <head>. وإن كنت تستخدم npm فالخيار الثاني يناسبك.

الرابط المباشر (CDN)

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dawod/thmanyah-font-web/index.css" />

عبر npm

npm install @dawod/thmanyah-font-web

// ثم في ملف الدخول
import "@dawod/thmanyah-font-web";

استخدامه في CSS

اذكر أوزانه رقمًا: 300 و400 و500 و700 و900.

body {
  font-family: "Thmanyah Sans", sans-serif;
}
h1, h2 {
  font-family: "Thmanyah Serif Display", serif;
  font-weight: 700;
}
article p {
  font-family: "Thmanyah Serif Text", serif;
}

حزمة مجتمعية لخط ثمانية على الويب، وليست إصدارًا رسميًا.
